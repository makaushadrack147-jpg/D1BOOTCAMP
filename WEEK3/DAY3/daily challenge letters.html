How it works:

This input field automatically removes any character that is not a letter (a-z, A-Z). Numbers, spaces, and special characters are rejected.

Examples:
  • Input: hello123 → Output: hello
  • Input: Test@456 → Output: Test
  • Input: abc!@#xyz → Output: abcxyz
  • Input: H3LL0 → Output: HLL
